Access Control Panel

How to give access to a page

  1. User access — select a user, choose Custom, then click a page to grant access and configure visible components.
  2. Each page can have full access or hide specific buttons, sections, tables, and fields.
  3. To allow re-opening a closed visit, tick Open Closed Visit under Patient Management (Custom access).
  4. Role access — select a role and tick API actions that role may perform (e.g. stock transfer).
  5. Click Save. Users must log in again for changes to apply.

Roles without endpoint access cannot call protected APIs even if they reach a page. Admin and MD always have full access.
